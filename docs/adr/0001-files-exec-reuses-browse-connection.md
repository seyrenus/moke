# 文件页的命令执行复用浏览连接，不另建、不借会话

文件页做 git diff 需要在远端跑命令（`git diff HEAD` 等）。我们决定在文件页已有的那条 SSH 连接上多路复用开 exec 通道（`SftpSession` 增加 `exec`），而不是每次另建短连接，也不优先复用终端会话的 `transport.exec`。理由：零额外握手；从终端进、从连接列表进、mosh 主机三种情况行为一致（与 `SftpSession` 独立连接的既定哲学同源）。被拒的「会话优先」方案会让 diff 可用性随会话状态漂移，还多出一条代码路径；大传输不走文件页这条连接，不存在 SSH 窗口争抢。
